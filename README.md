# Gomboc Code Remediation Skill for Claude Code

**Deterministic code remediation for any codebase — powered by Gomboc.ai.**

The perfect complement to agentic coding systems. Scan, fix, and improve code across infrastructure, applications, and configurations with 94%+ accuracy.

## What It Does

- 🔍 **Scan** any codebase for issues
- 🔧 **Generate** merge-ready fixes with 94%+ confidence
- 🤖 **Perfect for agents** — deterministic remediation paired with AI
- 📊 **Multiple formats** — JSON, Markdown, SARIF

## Quick Start

```bash
# Scan code
@gomboc scan path:./src

# Generate fixes
@gomboc fix path:./src format:pull_request

# Apply fixes
@gomboc remediate path:./src commit:true
```

✅ Deterministic AI (no hallucinations)
